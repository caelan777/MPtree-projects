# Microsoft Store listing, ready to paste

For MPTree for Windows in Partner Center. How the package itself is made and sent
in is in [Desktop/store/README.md](../Desktop/store/README.md). No em or en dashes
anywhere, on purpose.

Privacy policy URL: **https://mp-tree.net/privacy**
Website: **https://mp-tree.net**
Support contact: the address MPTree's feedback emails go to.

The package says it speaks English, Dutch and Spanish, so Partner Center asks for a
listing in each of the three. All three are below.

---

## Properties

- Category: **Music**
- Privacy policy: yes, the URL above (the app goes online for the account and the
  update check, so one is required).
- System requirements: Windows 10 version 1809 or later, 64-bit. Nothing else to tick.
- Product declarations: none of them apply. The app does not depend on a
  Microsoft account, and it is not for children in particular.

## Pricing and availability

- Price: **Free**.
- Pro is not sold through the Store's own system. Non-game apps may use their own
  payment (Microsoft Store Policies 10.8.1), and MPTree Pro on Windows is a web
  checkout tied to the MPTree account. Until that shop is open the Store build has no
  Buy button at all, only the free week, so there is nothing to declare yet.

## Restricted capability: runFullTrust

Partner Center asks why the package needs it. Paste:

```
MPTree is a desktop app (Win32, built with Tauri) and runs as a regular desktop
program. It reads the user's own audio files from their user folder or the folder
they pick, saves cut tracks as new files in Music\MPTree, and keeps a cache of song
tags so the library opens quickly. None of that works inside the app container.
```

## Age rating questionnaire (IARC)

Category: **Utility / Productivity / Other** (a music player).

- Violence, sexuality, language, controlled substances, gambling: No
- User generated content or users talking to each other: No (the account only syncs
  between the user's own devices)
- Shares location: No
- Digital purchases: **Yes** (MPTree Pro, once the shop is open; answering yes now
  saves changing it later)

Expected outcome: all ages (PEGI 3, Everyone).
